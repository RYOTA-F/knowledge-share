# ナレッジの共有

社内/コミュニティ向けの勉強会・イベントで使用した資料やトピックをまとめたリポジトリです。各イベントごとにディレクトリを分け、当日使用したスライド相当の Markdown と画像を格納しています。

## ディレクトリ構成

```text
knowledge-share/
├── README.md     # このファイル
└── event/        # 勉強会・イベント資料のルート(イベント単位でサブディレクトリを作る)
    ├── 2026_0401_ClaudeCode/     # Claude Code 勉強会(2026-04-01)
    └── 2026_0415_OpenClaw/       # OpenClaw 勉強会(2026-04-15)
```

## 階層の役割

| 階層 | 役割 |
| --- | --- |
| `event/` | すべてのイベント資料の置き場所。 |
| `event/<日付>_<イベント名>/` | 1 回のイベントに対応するディレクトリ。命名規則は `YYYY_MMDD_イベント名`。 |

## 開催済みイベント

- [Claude Code 勉強会(2026-04-01)](./event/2026_0401_ClaudeCode/イベントトピック.md) — Claude Code の基礎と、AI との向き合い方。
- [OpenClaw 勉強会(2026-04-15)](./event/2026_0415_OpenClaw/イベントトピック.md) — OpenClaw の全体像・SKILL.md / SOUL.md・セキュリティ・カスタマイズまで。

## 新しいイベントを追加するとき

1. `event/YYYY_MMDD_イベント名/` ディレクトリを作成する。
2. 直下に `イベントトピック.md`(目次・進行表)を置く。
3. 発表内容は `topics/` 配下に 1 トピック 1 ファイルで追加する。順序がある場合は `01_`, `02_` … のプレフィックスを付ける。
4. 画像は `images/` にまとめ、Markdown からは相対パスで参照する。
5. この README の「開催済みイベント」にリンクを追記する。
