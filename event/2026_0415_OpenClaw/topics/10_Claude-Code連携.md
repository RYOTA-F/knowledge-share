# Claude Code連携

## Claude Codeって何？

**Claude Code**（クロードコード）は、Anthropic社（Claudeを作っている会社）が提供する、プログラミング専門のAIツールです。エンジニアがコードを書くときの相棒として使います。

## OpenClawと何が違うの？

両方ともAIエージェントですが、**得意分野が違います**。同じ料理人でも、和食が得意な人と洋食が得意な人がいるのと同じです。

### OpenClawが得意なこと

- **スケジュール実行**: 毎朝・毎時などの定期作業
- **通知**: チャットアプリへのメッセージ送信
- **リモート操作**: 外出先からスマホで指示
- **マルチサービス連携**: いろんなアプリを横断する自動化
- **日常の自動化**: 生活・業務の雑務

→ **「生活・業務の執事」**

### Claude Codeが得意なこと

- **デバッグ**: プログラムのバグ探し
- **テスト**: 動作確認の自動化
- **コードレビュー**: 書いたコードの品質チェック
- **リファクタリング**: コードを整理して書き直す

→ **「プログラミングのパートナー」**

## 2つを組み合わせると強い

両方を連携させることで、さらに便利になります。3つのパターンを紹介します。

### パターン1: リモートコーディング

外出先からLINEで「このバグ直しといて」と送ると、OpenClawがClaude Codeに伝えて、コード修正まで自動でやってくれる。エンジニアは電車の中でもスマホから開発ができます。

### パターン2: 定期的なコード品質レビュー

毎週金曜の夕方に、OpenClawがClaude Codeを呼び出してコード全体をチェックしてもらう。「今週増えたバグの種」をSlackにレポートしてくれる、というような使い方です。

### パターン3: インシデント自動対応パイプライン

Webサイトが落ちるなどのトラブルが起きたとき:

1. 監視ツールがOpenClawに通知
2. OpenClawが状況をClaude Codeに伝える
3. Claude Codeが原因を特定して修正案を作る
4. OpenClawがエンジニアのスマホに「こう直そうと思います、OK？」と確認
5. 承認すれば自動で修正実行

人間が寝ている間にも問題が解決していく、という未来的な使い方です。

## 非エンジニアの方へ

「自分には関係ないかも」と思うかもしれませんが、この話のポイントは「**AIツールは1つに絞らず、得意分野で使い分ける時代が来ている**」ということです。仕事でも、人を適材適所で配置するのと同じ感覚です。
