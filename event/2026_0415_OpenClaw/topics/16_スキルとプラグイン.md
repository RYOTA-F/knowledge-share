# スキルとプラグイン

## AIに「できること」を足していく仕組み

OpenClawはそのままでも賢いですが、「スキル」や「プラグイン」を追加することで、新しい仕事を覚えさせることができます。スマホに新しいアプリを入れるようなイメージです。

## スキル（Skill）とは

**「こういう手順でやってね」という指示書**のようなもの。文章で書かれているので、プログラミングができなくても作れます。

- 形式: `SKILL.md` という名前のテキストファイル
- 動く場所: 作業員役（Executor）が、必要なときだけ呼び出す
- 例: 「毎朝天気を調べて日本語でまとめて送るスキル」

## プラグイン（Plugin）とは

**プログラマーが書いた本格的な拡張機能**。スキルより高度なことができます。

- 形式: コード（プログラム）
- 動く場所: 受付係役（Gateway）の中で常に動く
- 例: 新しいメッセージアプリ対応、複雑な画像処理

## どっちを使えばいい？

| やりたいこと | 選ぶもの |
| --- | --- |
| 決まった手順を自動化したい | スキル |
| 新しい機能を本格的に追加したい | プラグイン |
| プログラミングできない | スキル |
| プログラミングができる | どちらでもOK |

## 100以上の「最初から入っているスキル」

インストール直後から使えるスキルが100個以上あります。メール送信、ファイル整理、天気取得など、よくある作業はだいたい揃っています。

## ClawHub（クロウハブ）というお店

**ClawHub** は、世界中のユーザーが作ったスキルを共有する「AppStoreのようなマーケットプレイス」です。2026年時点で**13,729個以上**のスキルが登録されていて、気に入ったものをダウンロードして使えます。

> ⚠️ ただし、後述のセキュリティ注意事項にある通り、悪意あるスキルも混じっているので、使う前に中身を確認することが大切です。

## 自分のスキルを作ってみよう

`SKILL.md` は普通の文章ファイルなので、やりたいことを手順として書けば完成。たとえば:

```text
1. ニュースサイトを開く
2. トップ5記事を取得する
3. 日本語で3行に要約する
4. Slackに送る
```

のように書くだけで、AIが理解して実行してくれます。
