# 参考リソース（もっと知りたい人へ）

イベント後、自分でもっと学びたい人向けの情報源をまとめました。**無料で読めるものが中心**なので、気軽に覗いてみてください。

## 公式リソース（一番信頼できる情報）

### GitHub（ギットハブ）

OpenClaw本体のソースコードが公開されている場所。英語ですが、READMEという最初のページだけでも読む価値があります。

- 何があるか: 最新バージョン、不具合報告、使用例
- 使い方: 「Issues」というページで他ユーザーの質問・議論が読める

### 公式ドキュメント

作者が書いた説明書。機能の詳しい解説・設定方法が載っています。

## 英語記事

世界的なメディアが紹介しているので、検索で見つかります。

- **KDnuggets**: データサイエンス系メディア。技術的な深い解説
- **freeCodeCamp**: 無料プログラミング学習サイト。初心者向け解説
- **Milvus Blog**: AI技術ブログ。応用事例が豊富

※英語が苦手でもブラウザの翻訳機能で十分読めます。

## 日本語記事

### Qiita（キータ）

日本のエンジニア向けブログサービス。「OpenClaw」で検索すると、実際に使ってみた人の体験談が読めます。**初心者向けの記事も多い**のが嬉しいところ。

### Uravation（ウラベーション）

技術系の日本語メディア。解説記事が丁寧。

## コミュニティ（仲間を見つける）

### Discord

OpenClaw公式のDiscordサーバー。ユーザー同士で質問・情報交換できる場所。

- 初心者向けチャンネルあり
- 新機能のお知らせが一番早い
- 英語中心だが、簡単な英語でOK

### Reddit（レディット）

海外の掲示板サイト。`r/OpenClaw` のような専用スレッドで話題が盛り上がっています。

## 関連ツールリスト

OpenClawと一緒に使うと便利なツール:

- **Node.js**: OpenClawを動かす土台
- **Git**: メモリやスキルをバックアップする
- **VSCode**: スキルファイル（SKILL.md）を編集するのに便利
- **各種APIキー**: OpenAI、Anthropic、Google など

## 情報の追い方（最新情報をキャッチする）

AI業界は変化が早いので、情報収集のコツも紹介します。

### 1. GitHub Watch

GitHubで「Watch」ボタンを押すと、新バージョンが出たときにメール通知が来ます。

### 2. Discord のアナウンスチャンネル

公式からの重要情報が一番早く流れる場所。

### 3. 開発者のX（旧Twitter）

作者のPeter SteinbergerさんのXアカウントをフォロー。新機能の予告やデモ動画が投稿されることがあります。

## 初心者へのおすすめ順

まずはここから始めると迷いません。

1. **Qiita**で日本語の「使ってみた」記事を読む
2. **公式ドキュメント**のクイックスタートを試す
3. **Discord**に入って質問してみる
4. **GitHub**でIssuesを眺めて最新の話題を知る

## 最後に

「全部読まなきゃ」と思う必要はありません。気になったものから1つずつで大丈夫です。**実際に手を動かして試すのが一番の学び**になります。
