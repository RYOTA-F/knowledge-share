# SKILL.md の書き方（OpenClawの心臓部）

OpenClawを使いこなす上で **絶対に避けて通れないのが `SKILL.md`** です。これさえ書ければ、AIに新しい仕事を任せられます。プログラミング不要で、文章だけで作れます。

---

## SKILL.md とは何か

**SKILL.md** = AIへの指示書（マニュアル）。
ふつうのMarkdownファイル（テキストファイル）です。

- ファイル名は固定で `SKILL.md`
- 中身は「いつ・どのツールを・どう使うか」を自然な日本語または英語で書く
- 実行時にAI（LLM）の **システムプロンプト** に自動で読み込まれる

→ つまり、**「AIの行動マニュアル」**です。

---

## なぜ Markdown なの？

| 比較 | コードで書く場合 | SKILL.mdで書く場合 |
| --- | --- | --- |
| 必要なスキル | プログラミング | 文章を書くだけ |
| 編集のしやすさ | 難しい | メモ帳でOK |
| AIとの相性 | 翻訳が必要 | 直接読める |
| バージョン管理 | できる | できる（Git対応） |

→ **非エンジニアでも作れる**のが最大の特徴。

---

## ファイル構成

スキルは**1つのフォルダ**で管理します。

```text
my-morning-briefing/      ← スキル名のフォルダ
├── SKILL.md              ← 必須（指示書）
├── helper.sh             ← 任意（補助スクリプト）
└── config.json           ← 任意（設定ファイル）
```

最小構成は `SKILL.md` 1つだけでOK。

---

## SKILL.md の中身（ひな型）

### 基本構造

```markdown
---
name: my-morning-briefing
description: 毎朝の天気・ニュース・予定をまとめて送る
triggers:
  - 朝 7:00
  - "おはよう"と言われた時
tools:
  - browser
  - file
---

# 朝のブリーフィング

## いつ使うか
- 平日の朝7時
- ユーザーが「おはよう」とメッセージした時

## やる手順
1. browser ツールで天気サイトを開いて今日の天気を取得
2. browser ツールでニュースサイトのトップ5記事を取得
3. file ツールで今日のカレンダーを読み込む
4. すべてを3行以内に要約
5. メッセージで送信

## 出力形式
- 1行目: 天気と気温
- 2行目: 重要ニュース1件
- 3行目: 今日の予定の最初の1件

## 注意
- 雨の場合は傘マーク 🌂 を先頭に付ける
- 予定が空の場合は「今日は予定なし」と書く
```

## 重要な2つのパート

### 1. YAML frontmatter（上の `---` で囲まれた部分）

ファイルの最初に書く**メタ情報**。AIではなく、OpenClaw自体が読む部分です。

| 項目 | 役割 |
| --- | --- |
| `name` | スキルの名前 |
| `description` | 何をするスキルかの説明 |
| `triggers` | いつ起動するか |
| `tools` | 使うツールの一覧（exec, browser, file 等） |

### 2. 本文（自然言語の指示）

AIが読む部分。**普通の文章で OK**。プログラミング言語ではなく、日本語や英語で書きます。

ポイント:

- やる手順を **箇条書き** で
- **「いつ」「何を」「どうやる」** を明確に
- 例外パターン（エラー時、空のとき等）も書く

---

## スキルの3種類

OpenClawには3つの場所にスキルがあります。

### 🟢 Bundled（バンドル）

OpenClawをインストールすると最初から入っているスキル。100個以上。

- 場所: OpenClaw本体の中
- 例: メール送信、ファイル整理、天気取得

### 🟡 Managed（マネージド）

ClawHub からダウンロードしたスキル。1.3万個以上から選べる。

- 場所: ClawHub レジストリ
- インストール: `openclaw install <スキル名>`

### 🔵 Workspace-level（ワークスペース）

**自分で作ったスキル**。`~/.openclaw/skills/` に保存。

- 場所: 自分のパソコン内
- 編集: メモ帳やVSCodeで自由に

---

## どうやって作る？（ステップ・バイ・ステップ）

### ステップ1: フォルダを作る

```text
~/.openclaw/skills/my-first-skill/
```

### ステップ2: SKILL.md をメモ帳で作る

```markdown
---
name: my-first-skill
description: テスト用のスキル
triggers:
  - "テストして"と言われた時
---

# テストスキル

## やる手順
1. "Hello, World!" とメッセージで返す
```

### ステップ3: 保存して読み込む

OpenClawを再起動すれば自動認識されます。

### ステップ4: 試す

メッセージで「テストして」と送信 → AIが反応してくれれば成功！

## 上級者向け: ツールとの組み合わせ

SKILL.md の中で **どのツールを使うか** を指定できます。

| ツール名 | できること |
| --- | --- |
| `exec` | パソコンのコマンドを実行 |
| `browser` | Webサイトを開く・操作 |
| `file` | ファイルの読み書き |
| `image` | 画像の処理 |
| `email` | メール送受信 |
| `calendar` | カレンダー操作 |

例: 「Webサイトを開いて、内容をファイルに保存する」

```markdown
## 手順
1. browser ツールで https://example.com を開く
2. ページの本文を取り出す
3. file ツールで `~/notes/today.md` に保存する
```

## よくある質問

### Q. プログラミング知識ゼロでも作れる？

**A. はい。** 文章を書ければOK。手順を箇条書きで書けるなら作れます。

### Q. 失敗したらどうなる？

**A.** AIが「うまくいかなかったよ」とメッセージで報告してくれます。SKILL.md を編集して試行錯誤しましょう。

### Q. 他人のスキルを使うのは安全？

**A.** ClawHubの一部スキルにはマルウェアが混入した事件（ClawHavoc）があります。**ダウンロード前に SKILL.md の中身を読む**ことを必ずやりましょう。怪しい命令（`rm -rf` 等）が書かれていないかチェック。

### Q. スキルを共有したい

**A.** ClawHubに公開できます。`openclaw publish` コマンドで誰でも投稿可能。

---

## まとめ

- `SKILL.md` = **AIへの自然言語マニュアル**
- 構成は **YAML frontmatter + 本文**
- **プログラミング不要**で書ける
- 3種類: **Bundled / Managed / Workspace**
- 作り方は**フォルダ作る → SKILL.md書く → 再起動**だけ
- セキュリティ: 他人のスキルは**中身を読んでから使う**

`SKILL.md` を1つでも自分で書けるようになると、OpenClawの世界が一気に広がります。**まずは「Hello, World!」スキルから挑戦してみましょう**。
