# 重要な概念（まずここを押さえよう）

OpenClawを理解するうえで絶対に知っておきたい「キーワード5つ」を、一番やさしい言葉でまとめました。これさえ分かれば、あとの章がスッと入ります。

---

## 1. Gateway（ゲートウェイ）＝ ハブ＆スポーク構造

OpenClawの心臓部にあるのが **Gateway（ゲートウェイ）** と呼ばれるソフトウェア。これが「司令塔」として全部をつなぎます。

### ハブ＆スポークって何？

自転車の車輪を思い浮かべてください。真ん中の軸（ハブ）から、何本ものスポーク（細い棒）が外に伸びていますよね。それと同じで:

- **ハブ** = Gateway（中心の司令塔）
- **スポーク** = 各アプリ、LLM、メモリ、ツール

全部の情報がいったん Gateway に集まり、Gateway が「次はこれをやってね」と指示を配ります。

### 技術的な住所

Gateway は `ws://127.0.0.1:18789` という場所で待機しています。

- `127.0.0.1` = 「自分のパソコン」という意味
- `ws://` = WebSocketという「双方向のおしゃべり回線」
- **外には出ない** = だから安心

## 2. ツール / スキル / プラグインの三層構造

OpenClawの拡張機能には**3つのレイヤー**があります。この区別は大事なので覚えておきましょう。

### 🔧 ツール（Tools）= AIが直接使える「道具」

AIモデルに最初から登録されている機能。「手」のような存在です。

| ツール | 何ができる？ |
|---|---|
| `exec` | パソコンでコマンドを実行 |
| `browser` | Webサイトを開く・操作する |
| `file` | ファイルを読み書きする |
| `image` | 画像を処理する |
| メール/カレンダー等 | 10カテゴリのビルトイン |

### 📝 スキル（Skills）= AIに渡す「レシピ本」

`SKILL.md` という**Markdown形式の指示書**。「いつ、どのツールを、どう使うか」を自然な言葉で書いた、AIへのマニュアル。

例: 「朝のブリーフィングスキル」というレシピ
1. browser ツールでニュースサイトを開く
2. 記事を取ってくる
3. file ツールでメモに保存する
4. メッセージで送る

### 📦 プラグイン（Plugins）= 全部入りの「パッケージ」

ツール + スキル + 接続先などを1つにまとめた配布単位。npm（プログラムの共有サービス）で公開されていて、インストールするだけで複数の機能が一気に入ります。

### 覚え方

- **ツール** = 手
- **スキル** = マニュアル
- **プラグイン** = 手＋マニュアルの詰め合わせ

## 3. プロアクティブ入力（24時間働く仕組み）

普通のチャットボットは、**あなたが話しかけたときだけ**動きます。OpenClawが特別なのは、**「時間」や「出来事」自体も入力**として扱えること。

| きっかけ | 動き方 | 例 |
|---|---|---|
| **ハートビート** | 30分ごとに自己確認 | 「やり忘れていることないか確認」 |
| **Cronジョブ** | 指定時刻に起動 | 「毎朝8時にニュース配信」 |
| **Webhook** | 外部の通知で起動 | 「GitHubに更新があったら通知」 |

→ **あなたが寝ている間も働いてくれる**のが最大の違いです。

## 4. 永続メモリ＋魂（MEMORY.md と SOUL.md）

「**コンテキストは忘れる。メモリは持続する**」がOpenClawの設計哲学です。
ここで重要なのが **2つの特殊ファイル**:

### MEMORY.md（記憶）

AIの**長期記憶**。大事な情報がずっと保存されます。

- あなたの好み・プロフィール
- 過去のやり取り
- 学習した事実

→ 使えば使うほど、あなた専用のAIになっていきます。

### SOUL.md（魂・性格）

AIの**人格・口調・価値観**を定義するファイル。MEMORYと並ぶOpenClawの目玉概念。

- AIに「あなたはこういう人です」と設定
- 全会話に自動適用される
- 「丁寧な秘書」「カジュアルな相棒」など好きな性格に

→ MEMORY が「**何を覚えているか**」、SOUL が「**どう振る舞うか**」を決めます。詳細は [SOUL.md 詳細](07_SOUL-md-詳細.md) 参照。

### Markdownで保存する利点

- 自分で中身を見られる（ブラックボックスじゃない）
- 編集・削除も手でできる
- Gitでバックアップ・改ざん検知ができる
- ⚠️ 逆に、悪意あるスキルから書き換え攻撃の標的にもなる(後述)

---

## 5. ClawHub（スキルのApp Store）

世界中のユーザーが作った **スキル（SKILL.md）** を共有するマーケットプレイスが [clawhub.ai](https://clawhub.ai)。

| 項目 | 内容 |
|---|---|
| スキル数 | 13,729個以上（2026年2月時点） |
| 検索方法 | セマンティック検索（意味で探す） |
| カテゴリ | 天気、メール、コンテンツ作成、Webスクレイピング等 |

**自動インストール機能**もあり、AI自身が「このタスクに必要なスキル」を ClawHub から探してダウンロードできます（＝自分で自分を拡張する）。

---

## まとめ:この5つが核

1. **Gateway** = 中央の司令塔（ハブ＆スポーク構造）
2. **三層構造** = ツール・スキル・プラグインの役割分担
3. **プロアクティブ入力** = 24時間自律で動く仕組み
4. **MEMORY.md + SOUL.md** = 忘れない記憶 + 人格設定
5. **ClawHub** = 1.3万以上の既成スキルが使えるマーケット

これらが組み合わさって、「**自分のパソコンで動き、チャットアプリから操作でき、24時間働き、あなたの好みを覚えてくれるAI**」が実現されています。
