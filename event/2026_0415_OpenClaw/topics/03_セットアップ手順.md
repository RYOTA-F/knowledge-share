# セットアップ手順（始め方）

## インストールとは？

アプリをパソコンに入れること。スマホでいう「App Storeからダウンロード」と同じイメージです。OpenClawは「ターミナル」という黒い画面から1行コマンドを打つだけで入ります。

```
npm install -g openclaw@latest
```

これは「最新のOpenClawを、パソコン全体で使えるように入れてね」という意味です。

## 最初の設定（オンボーディング）

インストール後、**ウィザード**（質問に答えるだけで進む設定画面）が立ち上がります。次の4ステップで完了します。

### ステップ1: セキュリティ監査

「あなたのパソコン、安全ですか？」と自動チェック。鍵がかかっているか確認してくれる感じです。

### ステップ2: AIプロバイダー選択

脳みそ役のAIを選びます。

- OpenAI（ChatGPTの会社）
- Anthropic（Claudeの会社）
- Google（Geminiの会社）
- など

どれもAPIキーと呼ばれる「利用券」が必要です。

### ステップ3: メッセージングアプリ選択

どのアプリで操作するかを選びます。Telegram・Slack・Discordなど、普段使っているものを繋げればOK。

### ステップ4: デーモンサービス登録

「デーモン」とは、パソコンの裏でずっと動いてくれる番犬のこと。登録しておくと、パソコンを再起動しても自動でOpenClawが待機してくれます。

## 設定ファイルはどこにある？

`~/.openclaw/` というフォルダの中に全部入っています。`~` は「自分のホームフォルダ」という意味の記号です。

## つまずきポイント

- **APIキー**: 有料のAIサービスを使う場合は料金がかかります。月額上限を設定しておくと安心
- **Node.js**: `npm` コマンドを使うにはNode.jsという土台が先に必要
